
# County Rainfall and Planting Advisory

## Project Summary

This project analyses monthly rainfall readings from five Kenyan counties using Python and NumPy. It demonstrates data cleaning, exception handling, numerical analysis and CSV file generation. The objective is to help a farmer-support NGO identify suitable planting windows using historical rainfall patterns.

## How to Run the Notebook

1. Download `rainfall_analysis.ipynb` from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook and select Runtime → Run all.
4. The notebook generates `rainfall_summary.csv` containing the rainfall analysis results.

## Planting Advisory

- Nairobi, Nakuru, Kisumu and Mombasa: April–May is the recommended planting window.
- Machakos: November–December is the recommended planting window.
- These recommendations are based on historical rainfall readings and should be supplemented with local weather forecasts and farming conditions.
